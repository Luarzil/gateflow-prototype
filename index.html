    Scanned-badge override by location

    When a location's override is on, a driver whose badge is scanned there can leave without a daily authorization, as long as the driver is active, the license is current, and nobody revoked the driver's authorization today. A typed employee # is never covered; it still needs a Fleet Lead or above. Every exit the override allows is recorded as a location override, not as authorized.

    Only the Admin sees this tab, and the shared records accept a switch change from the Admin's login only. Every change is confirmed and recorded.
